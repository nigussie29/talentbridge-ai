# TalentBridge AI — 3-Minute Product Demo

Use the in-app **3-Minute Demo Studio** in the **Beta Test Center** as the
canonical timed recording guide. It includes the current narration, privacy
checklist, and a downloadable plain-text script.

## Recording setup

1. Use fictional, public, or consented demonstration inputs.
2. Hide names, email addresses, saved private records, and account details.
3. Close browser and desktop notifications.
4. Set browser zoom to 100% and use a 16:9 recording frame.
5. Run **Production Health Check** and confirm **Operational**.

## Story arc

| Time | Section | Purpose |
|---|---|---|
| 0:00–0:15 | Opening | State the problem and TalentBridge value. |
| 0:15–0:40 | Reusable inputs | Show private saved resumes and job descriptions. |
| 0:40–1:20 | Match results | Explain the three scores and analysis confidence. |
| 1:20–1:55 | Evidence | Show traceability, strength, and critical requirements. |
| 1:55–2:20 | Decision | Show the guarded application recommendation. |
| 2:20–2:45 | Growth | Show learning, interviews, portfolio, and progress. |
| 2:45–3:00 | Closing | Restate the product value and disclaimer. |

## Public-demo rule

TalentBridge results are evidence-based guidance, not an employer decision.
They do not verify proficiency or guarantee an interview.
